ENGINEERING STUDIO - Package 2
Contents: Draw 2D (lines, rectangles, circles, text, dimensions, snap, move, copy, rotate 90, undo, print PDF), Pipe 3D sketch (3D, dimensions, cut list, 4-view print sheet), Calculators, Field Handbook.

QUICK START (no install, works offline)
1. Extract the ZIP on the phone. 2. Open index.html in Chrome.
(Saved jobs may not persist when opened from a file. For saving, use option B.)

B) INSTALL AS AN APP (recommended)
1. Upload the folder contents to GitHub Pages or any web hosting.
2. Open the website in Chrome on Android, then menu > Add to Home screen / Install app.
3. After the first load it works offline.

C) REAL APK: give your hosted URL to pwabuilder.com to generate an Android package.

NOT IN THIS PACKAGE YET: walls/floors/roofs, electrical drawing objects, UAE standards library, DWG/PDF import.
Check all dimensions with an engineer before fabrication.
